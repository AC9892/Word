## Ta’agra — local installation

TaagraCalligraphy.otf is installed in this local copy at the user’s request. [The author’s font page](https://www.taagra.com/scriptfont) permits personal use and prohibits redistribution. Download a compatible font there, then use **Language packs → Ta’agra → Choose local font**. The default font is served from local project files; an optional replacement is stored in this browser. Designers: Shaun Prizio (script), Emily Neuendorf (font). Preview uses contextual ligatures and zero letter spacing; PNG export draws complete lines to preserve shaping.
